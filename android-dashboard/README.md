# Sudha Vatika Dashboard Android app

A thin Android app (Capacitor) that opens the live staff dashboard
https://sudha-vatika.vercel.app/ full screen. Dashboard updates show up in the app automatically.
Staff sign in with their own email and password (or sign-in link), exactly as on the web.

The APK is built by `.github/workflows/android-dashboard.yml`: GitHub → Actions →
"Build Android dashboard app" → latest run → **Artifacts** → `sudha-vatika-dashboard-apk`.
